# 🔥 GTA Egypt Ultimate Online - Full Prototype

A React Native game featuring GTA Egypt with online/offline modes, Egypt map exploration, vehicle selection, and police chase mechanics.

## 🎮 Features

- **🚗 Vehicle System**: 9 different cars with unique speeds (BMW, Mercedes, Ferrari, Bugatti, Tesla, etc.)
- **🌍 Multi-Country Travel**: Egypt, Italy, UAE, France with different police difficulty levels
- **🏙️ Egyptian Cities**: Cairo, Giza, Alexandria, Tanta, Mansoura, Luxor, Aswan, Sharm El Sheikh, Hurghada
- **👮 AI Police Chase**: Smart police that pursues the player with adjustable difficulty per country
- **💰 Money Collection**: Collect coins to earn money while evading police
- **📍 Location System**: Track current city and country
- **🌐 Online/Offline Mode**: Switch between game modes
- **🏪 Shops & Amenities**: Car shops, gas stations, garages, banks, cafes, malls
- **✈️ Airports**: Travel between countries
- **🎯 Mission System**: Dynamic mission updates based on player actions

## 🎮 Controls

- **⬆️⬇️⬅️➡️**: Move your vehicle (4-way directional controls)
- **Garage**: Select different vehicles with varying speeds and colors
- **Travel**: Move between countries with different police difficulty
- **Collect 💰**: Tap coins to collect money and increase your score

## 🌐 Game Mechanics

### Police AI
- Police automatically pursues the player
- Different countries have different police speeds
- Getting caught resets your money to 0 and resets police position

### Vehicle System
- Each vehicle has unique speed stat
- Color represents vehicle type
- Speed affects movement rate in the game world

### Progression
- Earn money by collecting coins
- Missions update based on money and gameplay
- Avoid police to maintain your score

## 🚀 Getting Started

```bash
cd gta-egypt
npm install
npm start
```

Then select your platform:
- Android: `a`
- iOS: `i`
- Web: `w`
